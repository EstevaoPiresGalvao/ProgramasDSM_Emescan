# ProgramasDSM_Emescan
Dois jogos desenvolvidos por estudantes da EEEM Doutor Silva Mello em parceria com o programa de iniciação científica PIBIC promovida pela Emescan. O objetivo de ambos os jogos é promover a inclusão e conscientizar acerca do capacitismo e seus malefícios sociais. Esses programas rodam em qualquer navegador, mas usam a arquitetura Touch Screen.
